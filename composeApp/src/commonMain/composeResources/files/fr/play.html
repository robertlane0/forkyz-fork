Aide jeu

Sur ces écrans, vous résolvez votre puzzle !

Les écrans sont :

  • Écran principal - Tout le puzzle est affiché.
  • Liste des indices - Voir le puzzle comme une liste d'indices.
  • Notes - Pour prendre des notes et résoudre des anagrammes.

Écran principal

  • Le comportement du clavier peut être configuré dans les paramètres.
  • Appuyez sur la ligne d'indice en haut pour afficher / masquer le panneau d'indices.
  • Appuyez longuement sur la ligne d'indice pour ouvrir la page d'indices.
  • Appuyez longuement sur le tableau pour ouvrir des notes sur l'indice.

Appuyer sur le bouton Menu donne accès aux options suivantes :

  • Indices - Afficher un écran où vous pouvez parcourir les indices de travers et de bas pour tout le puzzle.
  • Notes - Afficher un écran où vous pouvez faire des notes sur l'indice et résoudre des anagrammes. Vous pouvez choisir entre des notes pour l'indice sélectionné, ou des notes à l'échelle du puzzle.
  • Zoom - Contrôler le zoom du tableau de jeu.
  • Afficher les erreurs - Surligner les cellules non résolues ou incorrectes en rouge. Les trois modes sont la grille (tableau entier), l'indice (indice sélectionné, une fois rempli), le curseur (la cellule sélectionnée). (Peut être désactivé si aucune clé de réponse n'est disponible)
  • Mode scratch - Editer directement l'indice (voir notes). Configurez afficher rayures sur le tableau dans les paramètres pour utiliser cette option au mieux.
  • Révélation - Proposer l'option de révéler la bonne solution à une cellule, un mot ou tout le puzzle. Une fois révélées, les cellules "trichées" ont un fond rose. (Peut être désactivé si aucune clé de réponse n'est disponible)
  • Info - Montrer les informations sur le puzzle que vous jouez.
  • Soutenir Source du Puzzle - Disponible si connu. Ouvre la page Web de la source pour apporter votre soutien (par exemple des abonnements à des journeaux).
  • Insertion spéciale - Insèrer tout caractère ou mot dans la cellule actuelle.
  • Demander de l'aide à ChatGPT -
    Obtenir un indice sur l'indice actuel avec ChatGPT. Nécessite une clé API configurable dans les paramètres d'interaction, et connexion réseau.
  • Partager - Partager la grille ou l'indice actuel.
  • Aide - Afficher cet écran
  • Paramètres - Afficher l'écran des paramètres de l'application.

Liste des indices

Sur l'écran de la liste des indices, vous pouvez également choisir :

  • Afficher tous les mots - Afficher chaque entrée de la grille sous son indice plutôt que d'afficher seulement l'indice actuellement sélectionné en haut.
  • Editer l'indice - Modifier le texte de l'indice actuellement sélectionné.

Notes

Sur la page des notes, si la prédiction des caractères anagrammes est activée, entrer « espace » pour accepter la prédiction. L'appui long sur un widget d'entrée de tableau copiera normalement le contenu vers widget actuellement sélectionné. Par exemple, sélectionner le widget principal du tableau, puis appuyer longuement les rayures va copier les rayures sur le tableau. L'appui long de la source anagramme va mélanger les lettres.

Vous pouvez également ajouter des drapeaux aux indices. Il y a un menu option pour définir la couleur, ou vous pouvez appuyer longuement sur la boîte du drapeau indice.
