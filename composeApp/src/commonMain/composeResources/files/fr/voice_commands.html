Commandes vocales

Si l'entrée vocale est activée, vous pouvez utiliser les commandes vocales suivantes.

Écran principal

  • Solution mot / Mettre mot - Entrer un mot dans la grille. Par exemple "mettre pomme de terre".
  • Lettre l - Entrer une seule lettre l dans la grille. Par exemple "lettre b".
  • Supprimer - Supprimer au curseur.
  • Effacer - Effacer le mot sélectionné.
  • Numéro n - Sauter au numéro d'indice n. Par exemple "numéro 27".
  • Basculer - Changer la direction de indice sélectionné.
  • Suivant/précédent/saut - Aller à l'indice suivant / précédent / aléatoire.
  • Gauche/droite/haut/bas - Pareil que les touches fléchées.
  • Indices - Afficher l'écran de la liste des indices.
  • Notes - Afficher la page des notes de l'indice actuel.
  • Retour - Pareil que le bouton retour.
  • Annoncer - Annoncer l'indice actuel et le contenu du tableau. Utilisera le service d'accessibilité s'il fonctionne, sinon le service texte-vers-voix disponible.
  • Aide - Demander de l'aide à ChatGPT avec l'indice actuel. Nécessite une connexion réseau et une configuration de Chat GPT dans les paramètres d'interaction.

Écran de notes

  • Solution mot / Mettre mot - Entrer un mot dans la grille. Par exemple "mettre pomme de terre".
  • Lettre l - Entrer une seule lettre l dans la grille. Par exemple "lettre b".
  • Supprimer - Supprimer au curseur.
  • Effacer - Effacer le mot sélectionné.
  • Drapeau - Activer le drapeau sur l'indice actuel.
  • Couper mot - Entrer le mot dans le presse-papier. Par exemple, "couper pomme de terre".
  • Effacer couper - Effacer le presse-papier.
