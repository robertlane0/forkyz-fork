Keybindings

Keyboard shortcuts can be configured in these settings. Each entry is an action. For each action, enter a textual description of the key to bind. For example

PageDown
is the Page Down key. A complete list of key names is given below. Key names are not case sensitive.

Keys can be modified. E.g.

C-q
is ctrl+q. I.e. pressing the control key and the q key at the same time.

Available modifiers are

  • A- for the alt modifier,
  • C- for control,
  • S- for shift, and
  • M- for meta.

Modifiers can be combined. E.g.

C-S-q
is ctrl+shift+q. I.e. pressing control, shift, and the q key at the same time.
