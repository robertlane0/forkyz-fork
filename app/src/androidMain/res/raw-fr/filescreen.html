Aide de la liste des puzzles


Parcourez la liste des puzzles et sélectionnez-en un pour y jouer. Vous pouvez également "Appuyer Longuement" sur un puzzle pour le supprimer, ou le déplacer dans la vue "Archive". Vous pouvez également appuyer sur le bouton flottant pour importer des puzzles.


Flottant + Bouton


Appuyer sur le bouton flottant (+) donne accès aux options suivantes :


• Sources en ligne - Ouvre une page avec des liens vers des sites Web où des puzzles peuvent être téléchargés
• Importer un Puzzle - Importer un puzzle depuis votre appareil. Forkyz va essayer de reconnaître le format de fichier automatiquement. Les puzzles peuvent être téléchargés à partir des sources en ligne, ou en utilisant des outils externes tels que xword-dl.
• Télécharger des Puzzles - Utiliser le téléchargement direct dans l'application à partir de sources configurées dans les paramètres.

Options du menu


Appuyer sur le bouton Menu de cet écran donne accès aux options suivantes :


• Aide - Affiche cet écran
• Paramètres - Affiche les paramètres de l'application. Ici vous pouvez sélectionner les puzzles à télécharger et personnaliser le comportement de l'opération de Nettoyage.
• Archives/Mots croisés - Bascule entre la liste actuelle des mots croisés et le dossier d'archive
• Nettoyage - Déplace les puzzles terminés et anciens dans le dossier Archive. Si vous souhaitez les supprimer, au lieu de les déplacer dans le dossier d'archive, vous pouvez le spécifier dans les paramètres. Les fichiers puzzle ne sont pas si grands, ceci dit, et ne prendront pas une quantité significative d'espace sur votre périphérique de stockage externe.

Imports automatiques à partir du répertoire To-Import


Si vous utilisez un répertoire de mots croisés non internes (voir paramètres, emplacement de stockage), vous pouvez placer des fichiers dans le sous-répertoire to-import. Ces fichiers seront importés automatiquement la prochaine fois que la liste de puzzles sera affichée. Les fichiers importés avec succès seront déplacés vers to-import-done et vous pouvez les supprimer. Les importations qui ont échoué sont transférées vers to-import-failed.


Partager les Puzzles depuis un navigateur


Naviguez avec votre navigateur vers une page de puzzle, puis utilisez la fonction de partage pour partager l'URL de la page avec Forkyz. Forkyz va essayer d'importer le mot croisé.


Notez que cela ne fonctionne qu'avec un nombre limité de sites qui intègrent leurs mots croisés d'une manière que Forkyz peut reconnaître. Les exemples de sites incluent Crossword Nexus, Exolve, Guardian, Hamburger Abendblatt (récupéré depuis Raetsel Zentrale), De Standaard (récupéré depuis Keesing), Metro (récupéré depuis PA Puzzles), De Telegraaf (récupéré depuis Pzzl.net), Przekroj, Wall Street Journal.
