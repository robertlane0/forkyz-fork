## Calculating the Sources Array

Calculating the "sources" for the "forkyz" module means finding out what Gradle needs to download. To do this:

1. get a run log from Gradle that downloads (and logs) everything needed,
2. extract the downloads from the log file to make the sources for the Flatpak manifest.

For step 1, add to "build-options"

  "module" {
    ..
    "name": "forkyz"
    ..
    "build-options": {
      ..
      ,"build-args": ["--share=network"]
    }
  }

remove overwrite of settings.gradle.kts in "build-commands" and remove "--offline" so that gradlew can use the network. Add -i so you can see where downloads come from. I.e.

    "./gradlew -i --no-daemon packageReleaseUberJarForCurrentOS",

Delete all but the following two sources (or whatever Gradle version):

    {
      "commit": "cb85d8bb5cb1f28c5c2fa92419249238a73b50ee",
      "type": "git",
      "url": "https://gitlab.com/Hague/forkyz.git"
    },
    {
      "dest-filename": "gradle-9.2.1-bin.zip",
      "sha256": "72f44c9f8ebcb1af43838f45ee5c4aa9c5444898b3468ab3f4af7b6076c5bc3f",
      "type": "file",
      "url": "https://services.gradle.org/distributions/gradle-9.2.1-bin.zip"
    },

Then do (where `build-test` is any junk directory to delete later):

    $ flatpak-builder build-test manifest.json --force-clean > build-log.txt

Wait till completion as each stage may download more files.

Then, for step 2, run

    $ python get-sources.py build-log.txt > sources.json

It will take some time to download and calculate sha512 sums for all files. Then copy the contents of sources.json into the "sources" array of the manifest.

Currently the following dependencies don't parse properly, so will need manual adjustment (search sources, fix-up):

* jdom2

## DBus Fix

The flatpak manifests contain symlinking of the dbus library:

    {
      "build-commands": [
        "mkdir -p /app/lib",
        "ln -sf /usr/lib/x86_64-linux-gnu/libdbus-1.so.3 /app/lib/libdbus-1.so"
      ],
      "buildsystem": "simple",
      "name": "dbus-compat"
    },

with /app/lib added to LD_LIBRARY_PATH in forkyz.sh. This is because isSystemInDarkTheme does not work on flatpak as the Linux native code tries to load libdbus-1.so, which is not provided on the runtime. Only libdbus-1.so.3 is. The code above creates a needed symlink so the native theme detection will work.
